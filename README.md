# WordPress Quickstart

Стартовый проект для разработки сайтов на WordPress: от самостоятельной HTML-вёрстки до интеграции в нативную PHP-тему и создания собственных расширений.

## Основной подход

- Сначала подготовьте и проверьте HTML, SCSS и JavaScript независимо от WordPress.
- Используйте PhpStorm как основную среду разработки.
- Компилируйте SCSS средствами Dart Sass и PhpStorm File Watchers. Обязательный Vite, Webpack, Gulp или npm-сборщик проекту не требуется.
- После утверждения макета перенесите разметку в PHP-шаблоны темы.
- Функциональность, не относящуюся к представлению сайта, размещайте в плагинах, а не в теме.

## Структура

- `frontend/` — независимая площадка для HTML-вёрстки и исходники SCSS.
- `wp-content/themes/quickstart/` — стартовая классическая PHP-тема.
- `wp-content/plugins/quickstart-tools/` — минимальная заготовка собственного плагина.
- `docs/` — инструкции по установке, frontend-разработке, теме и расширениям.

Ядро WordPress, пользовательские загрузки, локальная конфигурация и секреты в репозиторий не включаются.

## Начало работы

1. Установите WordPress в корень проекта штатным способом или подготовьте локальную копию сайта.
2. Скопируйте файлы репозитория в корень установки WordPress, не заменяя существующие конфигурационные файлы.
3. Откройте проект в PhpStorm.
4. Настройте компиляцию SCSS по инструкции [PhpStorm и Sass](docs/frontend/phpstorm.md).
5. Откройте `frontend/index.html` через локальный веб-сервер и начните вёрстку.
6. Активируйте тему **Quickstart** в панели WordPress.

Подробно: [установка и структура проекта](docs/installation.md).

## Автоматические проверки

GitHub Actions выполняет статические проверки без развёртывания WordPress:

- проверяет синтаксис PHP в теме и плагине на PHP 8.1–8.5;
- компилирует SCSS через Dart Sass;
- сравнивает результат компиляции с CSS-файлом темы, чтобы выявлять несинхронизированные исходники.

Эти проверки не запускают WordPress и не подтверждают работу шаблонов, хуков или интерфейса в реальном окружении.

## Требования

Ориентируйтесь на актуальные требования WordPress на [официальной странице](https://wordpress.org/about/requirements/). Код стартовой темы рассчитан на PHP 8.1 и новее; совместимость конкретного сайта также зависит от версии WordPress, плагинов и окружения.

## Принципы

- Нативный PHP и API WordPress без обязательных шаблонизаторов и frontend-фреймворков.
- Минимум зависимостей и простая структура.
- Разделение оформления темы и функциональности плагинов.
- Экранирование вывода, проверка входных данных и соблюдение API WordPress.
- Документация и комментарии в коде — на русском языке.
