# WordPress Quickstart

Стартовый проект для разработки и запуска сайтов на WordPress.

## Назначение

Проект предназначен для полного цикла разработки сайта: от самостоятельной подготовки HTML-вёрстки до её интеграции в тему WordPress и дальнейшего расширения функциональности средствами PHP и API WordPress.

Frontend на первом этапе разрабатывается независимо от WordPress с использованием HTML, SCSS и Vanilla JavaScript. Основная среда разработки — PhpStorm. Обязательный отдельный frontend-сборщик не предполагается.

## Состав проекта

Структура и набор компонентов будут определены после анализа существующих решений и проверки рабочего процесса. Цель — подготовить не только frontend-заготовку, но и полноценную основу WordPress-проекта: тему, конфигурацию, расширения, примеры и документацию.

## Документация

Документация проекта ведётся на русском языке. По мере формирования структуры инструкции будут размещаться в каталоге `docs/`.

## Статус

Проект находится на этапе разработки. Структура и состав Quickstart уточняются до начала реализации основных компонентов.
