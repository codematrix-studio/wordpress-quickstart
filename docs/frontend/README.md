# Предварительная frontend-вёрстка

Каталог `frontend/` — независимая площадка для HTML/CSS/JS до интеграции с WordPress. Установка WordPress на этом этапе не требуется.

## Структура

- `frontend/index.html` — страница предпросмотра.
- `frontend/scss/` — исходники SCSS и partial-файлы.
- `wp-content/themes/quickstart/assets/css/` — скомпилированные CSS-файлы.
- `wp-content/themes/quickstart/assets/js/` — JavaScript для тестовой страницы и темы.

## Рабочий процесс

1. Создавайте разметку в `frontend/index.html`.
2. Пишите стили в SCSS в каталоге `frontend/scss/`.
3. Настройте PhpStorm File Watcher для компиляции SCSS в CSS темы.
4. Запустите локальный HTTP-сервер с корнем проекта и откройте `frontend/index.html` в браузере. Сервер WordPress для этого не нужен.
5. После утверждения макета подготовьте установку WordPress и перенесите разметку в PHP-шаблоны темы, заменяя статические данные функциями и циклами WordPress.
6. Продолжайте изменять SCSS-исходники. CSS обновляется автоматически и подключается на сайте после интеграции.

## Интеграция

Не переносите весь HTML-документ в один PHP-шаблон. Общая оболочка располагается в `header.php` и `footer.php`, страницы — в соответствующих шаблонах, повторяющиеся элементы — в `template-parts/`.

Подключайте CSS и JavaScript через `wp_enqueue_style()` и `wp_enqueue_script()`. Динамический вывод экранируйте функциями WordPress. Не удаляйте SCSS после интеграции.

## Принципы

- HTML, SCSS и Vanilla JavaScript.
- Без обязательных Vite/Webpack/Gulp.
- SCSS — исходный код, CSS — результат компиляции.
- Сторонние библиотеки добавляются только под конкретную задачу.
