# Установка проекта

## Требования

- Локальный веб-сервер с PHP и MySQL/MariaDB.
- Установленный WordPress.
- PhpStorm для работы с исходниками.
- Dart Sass для компиляции SCSS.

Актуальные рекомендуемые версии PHP и базы данных указаны на [официальной странице требований WordPress](https://wordpress.org/about/requirements/).

## Размещение файлов

Репозиторий предназначен для размещения в корне WordPress-проекта.

1. Сделайте резервную копию сайта.
2. Скопируйте содержимое репозитория в корень установки WordPress.
3. Не заменяйте существующие `wp-config.php`, пользовательские файлы и настройки окружения.
4. Убедитесь, что каталог `wp-content/themes/quickstart/` находится на месте.
5. В панели администратора откройте **Внешний вид → Темы** и активируйте тему **Quickstart**.
6. При необходимости активируйте плагин-заготовку отдельно.

Если репозиторий клонируется первым, установите WordPress в этот каталог штатным способом. Файлы ядра не входят в Git; основные каталоги и конфигурационные файлы ядра исключены через `.gitignore`.

## Проверка frontend-площадки

Откройте `frontend/index.html` через локальный веб-сервер, обслуживающий корень проекта. Страница использует CSS и JavaScript из ресурсов темы. При открытии через `file://` относительные пути могут работать иначе, поэтому предпочтителен локальный HTTP-сервер.

## Конфигурация

Секреты, параметры базы данных, ключи API и адреса окружений храните в локальном `wp-config.php` или защищённой конфигурации хостинга. Не добавляйте реальные значения в примеры и коммиты.

## Обновление

Перед обновлением сравнивайте изменения Quickstart с файлами конкретного сайта. Не перезаписывайте без проверки индивидуальные шаблоны, настройки и расширения.
